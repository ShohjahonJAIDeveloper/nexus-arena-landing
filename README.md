# NEXUS Arena — продающий лендинг компьютерного клуба

Одностраничник с 3D-первым экраном, скролл-анимациями, встроенным ИИ-помощником
(квиз + ответы на вопросы), приёмом заявок в SQLite, уведомлениями в Telegram
и скрытой админ-панелью на `/admin`.

Всё работает одним процессом Node: сборщика нет, библиотеки (three.js, GSAP, Lenis)
раздаются из `node_modules` — сайт открывается даже без интернета.

---

## Быстрый старт

```bash
npm install
cp .env.example .env    # затем откройте .env и поменяйте пароль
npm run dev
```

Сайт: <http://localhost:3000> · Админка: <http://localhost:3000/admin>

| Команда | Что делает |
| --- | --- |
| `npm run dev` | запуск с автоперезагрузкой (nodemon) |
| `npm start` | обычный запуск |
| `npm run tg:test` | отправить тестовое сообщение в Telegram |
| `npm run db:stats` | статистика и последние заявки в консоли |
| `npm run db:reset -- --yes` | очистить базу (удаляет все заявки!) |

### Переменные окружения (`.env`)

```
PORT=3000
ADMIN_PASSWORD=свой-пароль         # вход в /admin
SESSION_SECRET=длинная-случайная-строка
TELEGRAM_BOT_TOKEN=                # можно оставить пустым
TELEGRAM_CHAT_ID=                  # можно оставить пустым
```

Без токена Telegram сайт работает полностью: заявки сохраняются в базу и видны в админке.

## Подключение Telegram (5 минут)

Выбран самый простой рабочий вариант: **бот отправляет сообщения в группу**.
Вебхук, публичный HTTPS и хостинг для бота не нужны — сервер сам ходит в Telegram API.

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя.
   Он выдаст токен вида `8123456789:AAH...` — это `TELEGRAM_BOT_TOKEN`.
2. Создайте группу (например «Заявки NEXUS»), добавьте туда бота и всех менеджеров.
3. Напишите в группе любое сообщение, затем откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   и найдите `"chat":{"id":-1001234567890}` — это `TELEGRAM_CHAT_ID`
   (у групп id отрицательный).
4. Впишите оба значения в `.env`, перезапустите сервер и проверьте:

```bash
npm run tg:test
```

Хотите слать в личку — укажите свой личный `chat_id` (сначала напишите боту `/start`).
Хотите в канал — добавьте бота администратором канала и возьмите его `chat_id`.
Код при этом менять не нужно: меняется только одна переменная.

  telegram.js         отправка сообщений через Bot API
  validate.js         нормализация телефона, проверка полей, антибот
  rateLimit.js        лимит запросов в памяти
  auth.js             сессия администратора (cookie + timingSafeEqual)
  routes/
    leads.js          POST /api/lead
    assistant.js      POST /api/assistant/start | /message
    admin.js          /admin и /api/admin/*
  assistant/
    engine.js         понимание вопросов: стемминг, синонимы, скоринг
    knowledge.js      база знаний: 19 интентов с ответами и кнопками

### Где менять контент

- **Цены, зоны, акции, адрес, телефон** — `server/club.js`.
  Оттуда их берут помощник, квиз и уведомления в Telegram.
- **Тексты на странице** — `public/index.html` (цифры дублируются вручную,
  держите их в согласии с `club.js`).
- **Ответы помощника** — `server/assistant/knowledge.js`: добавьте объект
  с `patterns` (ключевые слова) и `answer`.
- **Шаги квиза** — `server/assistant/quiz.js`, массив `STEPS`.

## Как устроен помощник

Внешний ИИ-API не используется: всё считается на сервере, бесплатно и офлайн.

1. **Нормализация** — нижний регистр, `ё → е`, убираем пунктуацию.
2. **Стемминг** — срезаем русские окончания (`цены`, `цену`, `цена` → `цен`)
   и возвратные `-ся/-сь` (`закрываетесь` → `закрыва`).
3. **Синонимы** — разные слова сводятся к одному смыслу
   (`почём`, `прайс`, `тариф`, `стоимость` → `цен`).
4. **Скоринг интентов** — совпадение фразы целиком (3 балла), всех слов (2),
   отдельного слова (1.8), опечатки по Левенштейну (1.0).
   Вопросительные слова («сколько», «как», «где») в счёт не идут.
5. **Порог уверенности** — уверенно отвечаем, при близких вариантах уточняем
   кнопками, при низком счёте честно говорим, что не поняли, и предлагаем квиз.

Квиз мягко предлагается после 2–3 ответов и на любом «ценовом» вопросе,
собирает цель визита → количество людей → зону → часы → дату → имя → телефон,
показывает расчёт стоимости и отправляет заявку с полными ответами.
Вся переписка сохраняется в `chat_messages` — даже если гость не оставил заявку.

Проверить качество распознавания: `node scripts/test-intents.js`

## Админ-панель `/admin`

- Страница отдаётся только роутом и лежит вне `public/` — по прямой ссылке
  на файл её не открыть. На всех `/admin*` стоит `X-Robots-Tag: noindex`,
  в `robots.txt` — `Disallow: /admin`.
- Вход по паролю из `.env`, сравнение постоянного времени, не больше
  5 попыток за 15 минут с одного IP. Сессия — подписанная httpOnly-cookie на 7 дней.
- Внутри: сводка (всего / сегодня / за неделю / новые / из квиза), поиск,
  фильтры по статусу и источнику, карточка заявки с ответами квиза, расчётом
  стоимости и полной расшифровкой диалога, смена статуса, заметка менеджера,
  экспорт в CSV (открывается в Excel без «кракозябр»).

## Защита от спама

- Скрытое поле-ловушка: заполнено — заявка отбрасывается.
- Форма, отправленная быстрее чем за 2.5 секунды, считается ботом.
- Не больше 5 заявок за 10 минут с одного IP, 40 сообщений помощнику в минуту.
- Ограничение длины всех полей, экранирование вывода в админке и в чате.

## Производительность и доступность

- 3D-сцена отключается сама: при `prefers-reduced-motion`, без WebGL,
  на экранах уже 900px и при 4 и менее ядрах — вместо неё градиентный постер.
- Рендер ставится на паузу, когда первый экран уходит из вида или вкладка
  неактивна. Пиксельное соотношение ограничено 1.75.
- Библиотеки грузятся динамически: если GSAP или Lenis недоступны, страница
  продолжает работать — появление блоков сделано на IntersectionObserver.
- Клавиатурная навигация, `focus-visible`, aria-подписи у кнопок.

## Что проверить после установки

1. `npm run dev` → сайт открывается, в консоли браузера нет ошибок.
2. 3D-сцена в первом экране двигается за курсором; на ширине 375px — постер.
3. Помощник отвечает на «сколько стоит час», «какое железо», «можно отметить др».
4. Квиз проходится до конца → заявка появляется в `/admin` и в Telegram.
5. Форма внизу: пустые поля не отправляются, валидная заявка даёт экран «Заявка принята».
6. `npm run db:stats` показывает новые заявки.
